Firebase setup instructions
  1. Open Firebase Console and create a project.
  2. In Project settings, add a Web app and copy its Firebase configuration JSON into the box above.
  3. Open Firestore Database and create a database.
  4. Set Firestore security rules appropriate for your event before sharing. Do not leave unrestricted public write access enabled for sensitive or official results.
  5. Host this HTML online, then paste the same configuration and connect on each device.

Firebase configuration identifies your project but is not a secret password. Database security rules control who can read or change the data.
